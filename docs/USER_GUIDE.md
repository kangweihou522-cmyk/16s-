## 1. 先明确你要回答的问题

先写下一句研究问题，例如“假设示例：处理组与对照组的细菌群落结构是否不同”。随后记录独立实验单位、分组、样本数、采样时间、提取批次、测序批次及已知干扰因素。不同问题需要不同证据：α 多样性回答单个样本的丰富度或均匀程度；β 多样性回答样本间群落差异；差异菌分析寻找与分组有关的分类单元；功能预测形成待验证的功能假设。

**独立样本数决定信息量，测序条数不能代替生物学重复。** 同一只动物多次采样不是多只动物；同一笼动物可能共享环境与菌群。若所有对照来自笼 A、所有处理来自笼 B，处理与笼位完全混杂，事后统计无法把两者分开。提取批次、性别、年龄、饮食和采样部位也可能混杂。当前基础分组检验与差异模型不能自动解决配对、重复采样、笼位或复杂协变量问题；复杂设计需另行建立模型并限制置换范围。

实验前应规划提取空白、PCR 阴性和必要的阳性对照。低丰度特征可能是真实成员，也可能来自试剂或交叉污染。仅凭丰度低、名字陌生或属于某个门，不能可靠判为污染；decontam 等方法需要阴性对照或 DNA 浓度等信息[15]。当前过滤流程不等同于正式污染识别。

## 2. 16S 测到了什么：基本原理和完整流程

16S rRNA 基因含保守区和可变区。引物结合保守区域，扩增所夹的片段，再由测序仪读取。短片段包含分类线索，但不同微生物可能具有相同片段，同一基因组也可能具有多个不同的 16S 拷贝。因此，16S 结果通常适合群落组成和属等层级的分析，不能保证每条序列都准确鉴定到种或菌株，更不能直接测出活菌数量、致病性或基因表达。

一条 FASTQ 记录含名称、碱基序列和逐碱基质量值。双端测序从同一个 DNA 片段的两端读取，得到 R1、R2。read 长度、扩增子长度、测序深度是三个量：前两者的单位是 bp，深度是每样本的序列数。假设示例：两端各 250 bp，不代表去引物后的目标片段长 250 bp，也不代表每样本有 250 条序列。

工作站的主要流程为：

1. 按 CSV 把已拆样 FASTQ 对应到样本，检查配对、序列结构与软件环境。
2. 根据数据来源确认引物处理，生成实际进入降噪的质量图。
3. DADA2 过滤、学习测序错误、推断 ASV；双端再拼接，去除嵌合体。
4. 分类、排除指定非目标特征，保存未抽平计数表与代表序列。
5. 建树，生成多深度抽平曲线，选择正式深度后计算 α、β 和分组统计。
6. 从保存结果绘图；按研究问题补做丰度导出、差异菌或功能预测。

ASV 是扩增子序列变体，即模型分辨出的具体序列；OTU 通常是按相似度聚类的序列集合。二者不是同义词。ASV 有利于精确追踪序列，但“一个 ASV = 一个物种”不成立[2,3]。不同区域、长度、截断和引物的数据，即使编号相似，也不能直接合并。跨批比较应核对完整代表序列、相同区域和处理流程，不能只拼接 ASV 名称或属表。

QIIME 2 的 `.qza` 保存有类型的数据，`.qzv` 保存可视化，两者还包含来源记录。它们不是普通图片，也不意味着已经通过生物学审查[1]。

## 3. Windows 首次部署、日常启动和更新

推荐使用[Windows 自选目录部署（方案 A）](WINDOWS_DEPLOYMENT.md)。它让 Windows 管理目录、快捷方式和下载更新，分析仍在现有 WSL Ubuntu 的 Conda 环境中运行。

1. 让旧分析完成或取消任务，再在旧服务窗口按 `Ctrl+C`。
2. 下载 GitHub 完整源码 ZIP，全部解压，双击 `部署工作站.bat`。
3. 选择安装目录，默认 `D:\16S分析工作站`，也可选 E 盘。不要只从压缩包里拖出单个脚本运行。
4. 部署检测现有 Ubuntu、用户和 Conda。它不迁移 WSL、不重装 QIIME/R、不搬走原数据。
5. 成功后从桌面快捷方式或 `启动工作站.bat` 打开，默认地址为 `http://localhost:8766`，保持服务窗口运行。

日常启动使用本机版本，不联网更新。需要更新时双击 `更新工作站.bat`；它通过 Windows 下载、核验并准备独立候选目录，任务运行中拒绝更新，失败保留原版。`检查环境.bat` 只检查，`停止工作站.bat` 只停止本安装所属的空闲服务。不要依赖关闭浏览器来停止后台分析。

新部署默认结果在安装目录的 `分析结果` 中。浏览器可能记得旧路径，可点击“使用部署默认目录”；这不会搬迁旧结果。历史数据通过“打开历史批次”选择原 run。默认环境分别为 `qiime2-amplicon-2025.7`、`16s-workstation-r`、`16s-workstation-ancom`、`lefse`、`picrust2`，可按本机实际名称修改。环境名存在不代表相应命令和依赖已安装。

旧 Git 目录仍可在 Ubuntu 内用 `bash 启动.sh`，默认端口可能是 8765；它的更新行为与方案 A 不同。识别当前页面时，应查看网页顶部的实际安装目录、版本目录和服务启动信息，避免连接旧后台。更完整的网络、日志和配置说明见部署文档。

## 4. 准备 FASTQ、四列分组表和文件夹

输入应是**已经拆分到每个样本**的 Phred33 FASTQ，支持 `.fastq`、`.fq` 及 gzip 格式。双端须保留未提前拼接的 R1/R2；真正的单端有自己的输入选项。已拼接 FASTQ 不能自动还原双端，本版阻止把它当普通单端送进 DADA2；FASTA 缺少逐碱基质量值，也不能进入本版 DADA2。可以向测序方索取未拼接 clean R1/R2，并确认清洗内容。

建议把原始数据、参考文件和结果分开保存。假设示例：`D:\16S项目\raw` 放 FASTQ，`reference` 放分类器和映射表，`results` 放工作站输出。原始 FASTQ 只读保留；输出根目录不能等于原始目录或其父目录，可以是其下新建的 results 子目录。

推荐四列 CSV，下面仅为格式示例：

```csv
SampleID,Group,forward,reverse
001,CON,batch1/001_R1.fastq.gz,batch1/001_R2.fastq.gz
002,TREAT,batch1/002_R1.fastq.gz,batch1/002_R2.fastq.gz
```

| 列名 | 含义与检查重点 |
|---|---|
| `SampleID` | 本次样本标识，唯一且不空；不必与文件名相同，前导零应保留 |
| `Group` | 分组名称，不能空；CON、con、CON 后有空格等应先核对 |
| `forward` | 该样本的 R1；单端时是唯一输入文件 |
| `reverse` | 双端 R2；真正单端留空，但保留表头 |

路径以**所选原始目录**为基准，不以 CSV 所在目录为基准。可以填相对路径或原始目录内的 Windows/WSL 绝对路径；目录外路径会被拒绝。含逗号的单元格用双引号包围。四列模式只读取表中列出的文件，同一文件不能重复指给不同样本。每方向每样本一个文件，不自动合并多 lane。

Excel 中先将 SampleID 列设为文本，再另存为 CSV UTF-8；已丢失的前导零无法由工作站恢复。两列 `SampleID,Group` 兼容旧文件名匹配，但遇到歧义、多 lane 或特殊命名时改用四列。运行前点击配对与序列结构检查，逐样本核对“样本—组—R1—R2”，不要只看总样本数。

## 5. raw、clean、unknown 与引物、条码

raw 表示尚需确认或处理原始结构；clean 表示有来源依据确认已经完成所需清洗；unknown 表示不知道处理状态。**文件名含 clean 不是证据，未检出预设引物也不证明已经 clean。** 最有用的信息是测序公司提供的真实引物序列、方向、barcode/spacer 位置和已执行步骤。

引物用于扩增目标片段；barcode/index 用于识别样本；接头用于测序文库。它们可能位于不同位置。CSV 只是文件与样本的对应表，不执行 barcode 拆样。输入若仍是未拆样混合文库，应先用正确索引信息完成拆样。

工作站每文件抽查前 1000 条 reads，在起点 0—60 bp 搜索完整候选引物及反向互补，检测最多容许一个替换，不据局部短匹配推定引物。至少抽到 20 条、匹配比例达 90%、方向与切除边界一致才推荐自动清洗。这些都是**工作站启发式阈值**，不是官方统一标准；前 1000 条检查也不是全文件完整性或逐条配对一致性的证明。

预设覆盖部分 341F、338F、806R 候选；同一个名称可能有不同实验序列。自定义可逐行填多条序列，每方向最多 8 条，每条 12—80 bp、至少 12 个非 N 位点。支持 IUPAC 简并字符，例如 R=A/G、Y=C/T、W=A/T、N=任意碱基；这描述可接受的碱基集合，不是测序质量分数。

确认需要清洗后，Cutadapt 按完整候选长度匹配、错误率 0.1，切除匹配引物及其前方附加序列[5]。抽样检测规则与实际清洗匹配规则不同。程序不会根据上游附加序列猜 barcode 身份，也不会猜测切除引物后未知 spacer 的长度。短扩增子可能被测穿，3′ 端出现对侧引物或接头，当前 5′ 端处理不能证明这些结构已清除。已确认 clean 不应再机械裁掉一遍。

检查 `sequence_structure.json/tsv`、处理前后计数、clean FASTQ 映射及残留检查。本版残留抽样匹配超过 5% 会停止后续 DADA2；5% 同样是工作站保护阈值。遇到未确认、反向异常或切点冲突，先核对真实序列和供应商说明，不能通过随意增加 trim 绕过结构问题。

## 6. 看质量图、选择截断、理解 DADA2

Phred 质量值满足 `Q = -10 log10(P错误)`，Q20、Q30 分别对应约 1%、0.1% 的单碱基错误概率。质量图横轴通常是 read 内位置，纵轴是该位置的质量分布。它不是每条 read 的完整轨迹，也不直接报告整个样本可保留多少序列。反向端质量下降常更早，不能因为两端测序长度相同就强制截断长度相同。

`trim-left` 从左端切除指定碱基；`trunc-len` 控制右端截断位置。引物处理确认后，额外左端 trim 默认 0。截断应兼顾质量和双端重叠，且必须看**进入 DADA2 的处理后质量图**。假设去引物后目标片段 420 bp、两端保留 240 和 210 bp，则预计重叠约 30 bp；若只保留 200 和 200 bp，预计无重叠。长度有天然变异时，单一估计不能保证所有序列都可拼接。

工作站自动建议先选至少 99% 抽样 reads 覆盖的最长位置，再在首个连续 10 个位置的 Q25 中位数低于 Q30 的窗口前截断。q2-demux 质量汇总默认全批随机抽样 10000 条，99% 仅指该抽样的长度覆盖，不能解释为每样本 99% 实际质控保留率。这里 Q25 是质量分布的第 25 百分位，**不是固定 Q=25**。连续窗口只评价汇总图，不对每条 read 执行滑窗修剪。建议不足 50 bp 时转人工判断；50 bp 仅界定该建议的适用范围。线程建议最多 4 个；最低全表丰度默认 1。以上均为可复核建议，不保证最优。

DADA2 用质量信息学习测序错误率，区分可能的真实变体与错误序列；它不是简单按 97% 相似度聚类[2]。当前参数依照接入的 QIIME 2 2025.7 实现固定记录[4]：

| 参数 | 当前设置 | 解释 |
|---|---:|---|
| `max-ee` | 每端 2 | 预期错误数为逐碱基错误概率之和；不是最多允许 2 个已知错字 |
| `trunc-q` | 2 | 遇到质量值不高于阈值的位置截短，仍受其他长度与过滤条件影响 |
| `min-overlap` | 12 bp | 双端至少有这么多重叠，按实际序列检验 |
| `max-merge-mismatch` | 0 | 本次拼接不允许重叠区域错配 |
| `chimera-method` | `consensus` | 按样本识别嵌合体，再综合各样本证据去除 |

嵌合体主要指 PCR 中由不同模板拼成的序列。此流程已去嵌合体，不需再叠加 USEARCH/gold 来声称完成同一步。实际顺序是过滤、降噪、双端拼接、去嵌合体。

查看逐样本 `input → filtered → denoised → merged → non-chimeric`：filtered 突降先查质量、长度与 maxEE；merged 突降先查重叠、方向、配对与残留结构；non-chimeric 突降再查 PCR 和嵌合体。双端以读对/合并序列理解计数。`dada2_retention.csv/json` 保存阶段保留率，分母为零时留空；低于 50% 仅触发启发式提醒，不自动删样。不要只看全批平均，不同组系统性丢失会影响比较。不存在适用于全部样本的“必须保留某百分比”金标准。

## 7. 分类、特征过滤与系统发育树

分类器根据代表序列与训练数据给出分类标签。选择与目标区域、方向、参考库和软件版本相容的 `.qza`；仅能读取文件类型不代表模型兼容。L2—L7 通常对应门、纲、目、科、属、种，标签受参考数据库和分类体系影响。未分类到属不等于不存在该微生物，可能只是片段信息或参考覆盖不足。

分类表的 `Confidence` 是分类模型输出的浮点置信信息，不是序列计数，也不是某分类绝对正确的概率保证。当前流程没有另设用户可调的 Confidence 后过滤；不要擅自把它转整数或把 0.7、0.8 等当作本项目已执行的额外标准。

当前工作站以细菌分析为目标，固定排除分类字符串含 `Archaea`、`mitochondria`、`chloroplast` 的特征，再执行全表最低总丰度过滤。这不保证仅剩细菌，未分类或其他真核信号仍可能保留。**古菌是真实微生物，并非普遍意义的污染。** 如果研究包含古菌、植物相关细胞器或目标本来就是这些信号，应先改变分析方案；选择古菌参考库不会恢复已经删掉的 ASV。每次都应比较过滤前后样本总量及分类组成。

最低丰度指一个 ASV 在全表样本中的计数总和，不是每个样本都必须达到该值。默认 1 避免额外删除低丰度 ASV；提高它可能减少噪声，也会改变丰富度、Chao1、检出率和核心菌群定义。不能先看显著性再反复调到理想结果。

工作站对过滤后的代表序列做 MAFFT 比对、掩蔽部分不可靠位置、FastTree 建树并生成有根树，供 Faith PD 与 UniFrac 使用[6]。树反映短扩增子所支持的近似关系；它不是全基因组进化史，也不等同于分类谱系图。树、特征表与代表序列必须对应同一批特征。

## 8. 抽平曲线和正式抽平深度

稀释/抽平是从每个样本无放回随机取相同数量序列。它可在当前距离与多样性流程中统一计数深度，但会丢弃序列，低于深度的样本会被排除。它并非所有微生物统计都必须使用的预处理；方法间有不同估计目标与适用条件[8]。

**抽平曲线**在多个深度重复抽样，诊断指标随测序量的变化；本版通常从 1 到最大深度取约 10 个点，每点 10 次。`max-depth` 是曲线终点，留空取过滤后最大样本计数；填值超过实际最大计数时按实际最大运行并记录提示。深度超过某样本计数时，该样本不再贡献该点，曲线右端可能只剩高深度样本，不能忽视样本数变化。

**正式抽平深度**是本次核心分析统一取多少条序列，独立于曲线终点。当前推荐取严格低于所有样本最低过滤后计数的最大正整百数：`((最低计数 - 1) // 100) × 100`。假设示例：最低 17105 推荐 17100；恰好 17100 则推荐 17000。这个规则旨在保留全部样本，是工作站选择，不是公认最佳深度，也不保证曲线已平稳。最低不超过 100、存在零计数或分组不足时，程序要求检查，不自动扔掉低深度样本。

另有独立曲线诊断：寻找三个深度点、末点至少为首点 1.2 倍，observed features 与 Faith PD 变化不超过 5%、Shannon 不超过 2%，每组至少 90% 原样本支持。它也是启发式，诊断候选不改变上述正式推荐，更不证明正式推荐点已经验证。缺数据或未找到平台时应人工查看。

选择深度时依次看：每样本计数、各组保留名单、曲线是否仍陡升、丢样是否破坏设计。每组至少保留 2 个样本只是程序可运行的下限，不代表统计功效充分。确定后核心分析只抽平一次，后续 α、β、统计和 R 图读取同一保存表；换深度是一次新的分析，需保留并解释理由。

## 9. 七项 α 多样性怎么读

α 多样性描述单个样本内部的群落特征，不能简单归结为“越高越健康”。下表中 `S` 为检出特征数、`pᵢ` 为样本内第 i 个特征比例；具体实现见 scikit-bio 与 QIIME 文档[7]。

| 指标 | 主要衡量什么 | 解读与限制 |
|---|---|---|
| Observed features | 实际检出的 ASV 数 | 直观丰富度，受深度、区域、过滤影响，不等于真实物种数 |
| Chao1 | 用低计数特征估计未观测丰富度 | 依赖 singleton/doubleton；降噪和低丰度过滤改变它们，不能当作无偏真实物种总数 |
| Shannon | 丰富度与均匀度，`-Σpᵢln(pᵢ)` | 多个因素可导致同样分值，须结合组成与其他指标 |
| Simpson | 本版为 `1-Σpᵢ²` | 更受优势特征影响；勿与 Simpson 集中度或倒数混用 |
| Pielou evenness | `Shannon/ln(S)` 的均匀度 | 不直接衡量丰富度；仅一个特征等情况可能无定义 |
| Faith PD | 检出特征在树上的分支长度总和 | 反映系统发育广度，依赖树质量与分支长度 |
| Good’s coverage | 常用形式 `1-singletons/总计数` | 反映当前抽样中低计数尾部信息；接近 1 不证明测全物种、无污染或功能完整 |

本版每项保存独立图。曲线中 Pielou 名为 `pielou_e`，核心向量名为 `evenness`，表示同类指标。DADA2 与后续过滤会减少极低计数特征，因此 Chao1、Good’s coverage 要特别谨慎；跨不同过滤流程直接比较可产生误解。

读箱线图时先看样本点、离群值、组内分散及样本数，再看组间检验。显著性字母是保存的两两比较结果摘要：共享字母通常表示未拒绝该对“无差异”的零假设，并不证明两组完全相同。若全部值相同或数据不适合检验，程序可能明确跳过；不应补造 P 值或字母。

<a id="guide-10"></a>

## 10. β 多样性、PCoA 与统计检验

β 多样性描述样本之间的差异。工作站当前四套距离回答的侧重点不同[9]：

| 距离 | 是否关注丰度 | 是否使用树 | 适合怎样理解 |
|---|---|---|---|
| Bray–Curtis | 是 | 否 | 分类单元的组成和丰度差异 |
| Jaccard | 主要看检出/未检出 | 否 | 成员集合的差异，对检出阈值敏感 |
| Weighted UniFrac | 是 | 是 | 带丰度权重的进化分支差异 |
| Unweighted UniFrac | 主要看检出/未检出 | 是 | 检出成员所覆盖分支的差异 |

PCoA 把距离矩阵投影到少数坐标轴。图上较近通常代表在该距离下较相似；轴百分比是排序表示的信息比例，不是处理解释率。二维图只展示一部分结构；当前椭圆为 t 数据椭圆，不是组中心置信区间或显著性证据。图上 PERMANOVA P 值来自完整距离矩阵，不是仅检验前两轴。部分距离有负特征值，保存的坐标不能充分恢复原始负值信息；注意原工具警告，不凭图独自判断。

PERMANOVA 用置换检验组别与整体距离结构的关系，常报告 pseudo-F、R² 与 P 值[10]。R² 是该模型/距离下解释的变异比例，不能理解为“处理造成了 R² 百分比细菌变化”。PERMDISP 检查各组到中心的离散程度[11]；若显著，组内分散差异也可能影响 PERMANOVA 解读。任组仅 2 个样本时本版跳过 PERMDISP 并记录原因，以避免退化结果。应同时报告可用检验、组大小及排序图，不能用一个结果自动抵消另一个。

P 值是在零假设与模型条件下得到当前或更极端结果的概率，不是“结果由偶然造成的概率”，也不是效应大小。一次筛查很多菌会增加假阳性机会；BH 等校正控制指定检验集合中的错误发现率 FDR[12]。q 值不等于该菌有 q 的概率为假。报告需说明校正范围，不能把各层级、各终点、各次试参中最小 P 值拼成一个结论。

基础 α 检验为总体/两两 Kruskal–Wallis，β 保存总体/两两 PERMANOVA 和 PERMDISP。BH 的范围分别为每个 α 指标内的两两检验、每个 β 距离与方法内的两两检验；七项 α 总体 P 和四项 β 总体 P 仍是原始 P，不能声称全流程已统一控制 FDR。KW 用近似分布，小样本尤其每组少于常用的 5 个时须谨慎，2 个只是运行下限。它们依赖独立性与适当置换；重复采样、配对或笼位设计不能直接当独立样本。

<a id="guide-11"></a>

## 11. 组成图、相对丰度与绝对菌量

计数表记录测到的序列，不是细胞数。相对丰度为每样本某特征计数除以该样本总计数，各项和为 1。假设示例：A 的细胞量不变而 B 大量增加，A 的比例仍可能下降。因此“相对丰度下降”不能直接写成“菌量减少”[13]。绝对量需额外的 qPCR、流式、加标或其他经验证的定量设计，并考虑 16S 拷贝数和提取效率。

当前分类组成使用过滤后的**未抽平表**，先逐样本转比例，再组内等权求均值，不把高测序量样本赋更大权重。表格通常保存 0—1 比例，图显示百分比；0.1 表示 10%，不是 0.1%。

分类绘图把目标层级为空及 norank、uncultured、unclassified、Incertae_Sedis 等归入 `Others`，同名标签求和。目/科/属默认展示 Top20，其余已知分类也并入绘图 Others；门/纲/种默认全量，可调整。Others 是展示合并项，不是一个物种；它变大可能源于未分类增多，也可能是 Top N 外分类增多。原始谱系、清洗映射及完整表仍保存，差异模型继续使用完整谱系计数。

组成图用于描述。某个色块大、组均值不同，或 Top N 排名变化，都不能单独当作统计差异或生物标志物证据。

## 12. ANCOM-BC2、ANCOM 和 LEfSe

差异菌分析要兼顾组成性、测序深度和多重比较。当前方法入口明确区分 ANCOM-BC2、QIIME ANCOM 与 LEfSe，不能混称“ANCOM-II”，它们的统计量也不能互相替换。

**ANCOM-BC2**读取过滤后、未抽平的整数计数，在所选 L2—L6 层级独立建模，当前公式是 `Group`，没有自动加入笼位、批次或个体随机效应[14]。默认全输入样本中非零检出比例门槛 0.1、样本计数下限 `lib_cut=0`、显著性水平 0.05，启用结构零及伪计数敏感性检查。这些是当前设置，不是普适最佳选择。门/纲分类单元太少时偏差估计可能不稳，不能以各层级显著菌数量多少评判效应强弱。修改 lib_cut 时查看 `sample_inclusion.tsv` 与实际入模样本，各组不足 2 个会停止该层级。

参考组决定主效应方向，留空优先 CON，否则第一组。假设参考为 CON，“TREAT versus CON”的正 LFC 表示模型估计的 TREAT 更高；改变显示颜色/顺序不改变参考。LFC 是对数尺度效应，不是 LDA，也不应未经核对底数就当倍数。图中误差线若标 `±SE`，表示标准误而非 95% 置信区间。

三组及以上同时有几类问题：`res.tsv` 是相对参考组的主效应；`res_global.tsv` 问是否至少存在组别差异；`res_pair.tsv` 是具体组对比较。总体显著不表示每对都显著；两两效应应读对应输出，不能用两个主效应相减后沿用原 q 值。主效应按每个系数分别 BH，两两采用官方混合方向 FDR 控制，不同层级无共同 FDR，也不能把控制参数 B=100 说成两两做了 100 次 bootstrap 验证。结构零 `[SZ]` 在常规过滤前判断，相关特征不进入后续 LFC 模型；其 NA 不是无差异，也不能解释成生物学绝对缺失或伪造“无限倍”。

QIIME ANCOM 是基于对数比的另一方法，保存 W 和总体拒绝判定[21]；它不等同于 ANCOM-BC2，当前入口也不产生 ANCOM-BC2 式两两效应。解释以相应阶段报告为准。

**LEfSe**结合非参数筛选与 LDA 效应量，当前使用未抽平计数转换的 CPM，即比例乘 10⁶[16]。只有 SampleID 与 Group，不推定配对或 subclass。默认 KW 阈值与官方一致性参数均为 0.05、one-against-all，多组可选更严格策略。没有独立 subclass 时官方按类别构造它，任一类别少于 10 个样本的一致性步骤采用中位数规则，不能声称每一步都完成 Wilcoxon P<0.05。LDA 分数是鉴别效应评分，**LDA=3 不是增加 3 倍或 1000 倍**，当前 LEfSe 结果也没有 BH FDR 校正。

本版先拟合保留得分，再默认展示 LDA>2。调整阈值预览仅筛选缓存分数，不重做 KW/LDA；柱图 Top N 同样只影响显示。谱系分支图表示分类关系，不是菌群互作网络或独立证据。LEfSe 与 ANCOM-BC2 的一致命中可供参考，但同一数据上跑两种方法不等于独立验证；标志物仍需独立队列、靶向实验或预先定义的外部验证。

差异热图和气泡图先按原结果筛选，再展示全部组的平均相对丰度。行 Z 分数突出同一菌在组间的相对高低，不能比较不同菌的绝对丰度；气泡大小、颜色深浅不表示显著性。查看完整候选表、q、效应、检出率和警告，不能只交付一张漂亮热图。

## 13. PICRUSt2、NSTI 与功能注释

PICRUSt2 利用 ASV 在参考树中的位置和已测参考基因组的性状，推断基因家族组成；先按标记基因拷贝数校正丰度，再得到功能预测[17]。输入是过滤后未抽平表与完全对应的代表序列，输出允许小数，不能当实测 reads 或细胞数。它不是宏基因组测序，更没有测 RNA、蛋白或代谢通量。可以写“预测的功能潜力有差异”，不能直接写“该通路表达上调”或“代谢产物增多”。

NSTI（nearest sequenced taxon index）反映与已测参考基因组的系统发育距离；通常距离更大意味着参考外推更远，但它不是准确率百分比，也没有普适合格线。官方样本加权 NSTI 对保留 ASV 使用标记拷贝数校正后的丰度权重，须结合被排除的 ASV 和 reads 一起看，低 NSTI 不证明功能正确。当前 `min_align=0.8`、`max_nsti=2.0` 是接入默认值，不能因丢失多自动放宽。缺失官方质控表会标 unavailable，不臆算排除原因[18]。

三类输出应区分：KO 是 KEGG orthology 功能同源组；EC 是酶学编号；MetaCyc pathway 由 PICRUSt2 的相应通路步骤推断。工作站另接收八列映射表：

```text
KO,L1,L2,L3,pathway_id,gene,KO_name,EC
```

映射可为 UTF-8 CSV/TSV，KO 形如 `K00001`，L2/L3 非空时须有父层级。这个文件只给**已经预测出的 KO 加注释并按分类求和**，不是 PICRUSt2 参考基因组库。相同 KO 可属于多个分类，分类总和可能超过原 KO 总量；分类相对丰度按该汇总表各样本总和重新归一，不能跨层级混用分母。

KEGG L1/L2/L3 或 pathway_id 下的 KO 求和只是注释聚合，不是 MinPath 等方法正式推断的 KEGG 通路丰度、通路完整性或活性。官方 MetaCyc 推断与这些求和需分别命名。当前未请求 stratified/per-sequence 输出，不能从功能总表声称已经得到各菌功能贡献。保存映射来源、版本、原文件 SHA256 和未映射 KO；不因注释名称熟悉就忽视预测不确定性。

## 14. 高级分析：核心菌群、排序与表型关联

高级模块使用可选独立 R 环境 `16s-workstation-advanced`，不改 QIIME 或绘图 R 环境。仅首次使用这些新高级方法时，双击根目录的 `安装高级分析环境.bat` 联网安装一次；常规分析无需重装。选择已完成预处理结果和 L2—L6 中一个层级，读取其未抽平原始计数；它与基础核心多样性的抽平输入不同。没有对应报告时，不能声称已经完成分析。

附加 metadata CSV 用 `SampleID` 字面匹配，不能省略本批样本。可含 Age、Sex、Batch、IL6 等列；Group 从原分组补入，若另提供必须一致，额外样本会记录为 ignored。先区分连续量与分类量，数字编码的处理组不是连续表型。缺失值按模型完整案例处理，查看实际样本数；秩亏、共线性和残差自由度不足会阻止推断。

**核心菌群与检出率**：默认某样本中计数至少 1 且相对丰度至少 0.01% 才算检出，核心出现率默认 80%，均可调且属启发式。输出全体及分组检出率；检出率是符合条件的样本比例，相对丰度是样本内比例，两者不同。读深、假零、污染与分类层级都会改变结果，须保存阈值、分母及逐样本判定。核心不意味着有益或因果关键。

**CLR-PCA**：特征筛选默认出现率 10%，CLR 伪计数默认 0.5；在筛选后计数子组成上加伪计数、相对几何均值取对数，再做中心化、不标准化的 PCA[13,19]。相对丰度的分母仍来自原全表，不因展示/筛选重定义。伪计数与保留特征会影响稀有菌，应做敏感性检查。PCA 是描述性探索，载荷方向不等于绝对量变化。

**PERMANOVA 与离散度**：高级模块对筛选后的相对丰度计算 Bray–Curtis 距离，以 Group 加协变量的边际检验做 PERMANOVA，所检验的模型项构成一族 BH。另做未调整协变量的总体中位中心、偏差调整 PERMDISP，要求各组至少 3 个样本。说明公式、置换与实际样本；位置与离散须分别判断。它与基础抽平距离输入不同，数值无需一致，不能择显著者报告。

**约束排序**：可选 Hellinger-RDA 或 Bray–Curtis dbRDA，解释变量默认 Group，可选控制列，控制项通过条件化处理。Hellinger 对原全表归一后筛选的相对丰度开平方再作线性约束排序，dbRDA 基于距离约束[20]。总体检验与边际项检验分别形成校正范围。报告变量、控制项、完整案例、解释率与置换检验；同批数据的受约束分离不能用作独立分类器验证，箭头也不证明因果。

**表型关联**：关联输入默认采用 CLR：在与 PCA 相同的筛选后计数子组成上加伪计数（默认 0.5），每个菌的变量是相对该子组成几何均值的对数比；也可选择相对丰度作探索性关联。随后与数值表型做普通 Spearman，或默认采用控制 Group 的 ppcor 偏 Spearman[22]；普通 Spearman 不调整协变量。每个表型按完整案例分析，BH/FDR 范围仍为所选全部 taxa×traits 的一族，应查看方向、有效样本数和校正结果。CLR 不等于绝对菌量，控制 Group 也不能消除全部混杂；相关不是因果。报告筛选、零替换/伪计数设置及敏感性分析，不因换变换后显著性改变而择优报告。

若附加表中 `AnimalID`/`SubjectID` 重复，模块跳过推断，只保留核心菌群与 PCA；它不支持重复测量模型。没有这些列也不证明样本独立。结果的 `02_statistics` 保存 RDS 缓存、diagnostics 与表格，`03_figures` 保存 PNG/SVG/PDF；图旁控件只读取缓存重绘，不重新拟合。复杂笼位、配对或纵向设计应使用相应外部模型。

## 15. 图片预览、单图修改与下载

首次出图可直接采用默认样式。分析结束后在“图片与样式预览”读取当前或历史结果，选中某张图，在右侧修改该图的尺寸、标题、字体及适用选项，点击“应用并预览此图”。它只生成当前图的新预览版本；“查看修改前”可对照，下载与当前显示版本一致。

尺寸通常以英寸计，PNG 的像素还受 DPI 影响；SVG/PDF 适合矢量编辑。合并 PCoA 的宽高表示整个画布。字号过大、文字很多或层级过多可能需要加大画布。Times New Roman 必须在实际绘图环境可用，缺失时明确选择已安装字体，例如 DejaVu Serif，而不是依赖 Windows 软件自动补字。

组别配色/顺序影响显示，不改变样本分组、参考组或模型方向。分类堆积图填色代表分类单元，组标记代表实验组。热图、气泡图、效应图和 LEfSe 各有不同数值含义，修改标题时仍须保留清楚的单位与尺度。

“仅重绘”和单图预览复用保存的抽平表、指标、PCoA 坐标、差异判定或 LDA 缓存，不重新降噪、抽平、拟合或置换。原结果及预览独立保留，`figure_request.json` 与参数记录说明来源。改变统计方法、参考组、样本或正式深度属于新的分析，不能靠改图完成。QIIME 原生 QZV 可在 QIIME 2 View 打开，该查看器需联网加载，工作站没有内置完整 QZV 查看器。

## 16. 结果文件、历史批次与可复现记录

每次任务创建独立 run，不覆盖原始 FASTQ 或旧分析。新建批次清除旧批次关联，保留常用软件和作图偏好；历史入口明确恢复相同来源下的完整结果。修改样本、分组或引物后，不能继续把旧质量结果当作新输入。失败的部分结果保留供诊断，但工作站不是任意步骤自动断点续跑工具。

| 位置或文件 | 用途 |
|---|---|
| `00_inputs`、manifest、metadata | 实际文件映射、分组与输入来源 |
| `01_import`、`02_primers` | 导入、质量图、清洗后 FASTQ 与残留检查 |
| `03_dada2`、`04_taxonomy_filter` | 完整 ASV 表、代表序列、降噪统计、分类和过滤表 |
| `05_phylogeny`、`06_rarefaction` | 比对、树、七项曲线与原曲线数据 |
| `07_diversity/diversity_*` | 本次保留名单、正式抽平表、指标、距离、统计及 R 图 |
| `10_abundance`、`11_extensions` | 完整丰度导出与各次扩展分析 |
| `09_execution_code` | 实际运行代码、参数及命令说明文档 |
| `说明.md`、`report.json` | 阶段输入、参数、计数、文件与完成/失败/跳过状态 |

复核至少保留：原始数据及校验值、CSV、真实引物、分类器及数据库版本、完整 run、`parameters.json`、`commands.jsonl`、`workflow.log`、软件版本、推荐依据与手动修改理由。QZA/QZV provenance 记录工具来源，但不替代实验设计和实验室记录。

随机抽平和置换重跑可能不同；不能仅凭源码相同声称逐数值完全复现。论文应报告具体软件版本、实际参数、过滤项、正式深度及丢样、检验与校正范围，而不只写“用工作站默认参数”。保存图片输入表比只保存 PNG 更有助于复核。

## 17. 常见问题与故障排查

| 现象 | 优先检查与处理 |
|---|---|
| 双击后网页打不开 | 用检查环境入口看 WSL/Conda；检查服务窗口及端口；方案 A 看 `日志/server.log`、`wsl-launcher.log` |
| 更新后还是旧错误 | 核对网页服务版本、程序目录、启动时间；停止旧后台，重新启动正确入口 |
| 找不到 FASTQ 或配对错误 | 核对四列路径基准、文件扩展名、R1/R2 列；勿用改名掩盖真实多 lane 或重复文件 |
| 引物未检出 | 核对真实序列、方向、处理说明；补充自定义候选，不自动判 clean |
| filtered 很少 | 查处理后质量、长度、额外 trim 和逐样本统计，不先放宽全部阈值 |
| merged 很少 | 查配对、方向、预计重叠、引物/附加结构，确认输入未提前拼接 |
| 某组抽平后没样本 | 看过滤后计数与保留名单，检查低深度原因，重新选择有依据的方案 |
| 分类失败 | 核对分类器类型、训练区域、方向及 QIIME/sklearn 兼容性；保存完整错误 |
| R 绘图失败但 QIIME 已完成 | 使用专用 R 环境，查依赖和字体；保留已完成结果，修复后仅重绘 |
| ANCOM-BC2 失败或 NA 多 | 查该层级 diagnostics、低检出、样本数、结构零和模型警告；NA 不填 0 |
| LEfSe 没显著菌 | 查分组、样本量、筛选策略和缓存得分；无命中是合法结果，不改阈值追求命中 |
| PICRUSt2 排除多 | 查比对、区域、NSTI 和参考覆盖；高保留不等于高准确，不自动放宽阈值 |

**为什么同样数据换深度 P 值不同？** 抽样改变输入，同时可能改变留样；置换也有随机性。预先定义主分析，保存其他选择作为敏感性分析。

**为什么 α 不显著但 β 显著？** 两组可有相近丰富度和均匀度，却由不同成员组成；它们回答不同问题。

**为什么 Shannon 更高不等于更健康？** 健康含义依赖宿主、部位、疾病与功能；某些正常生态位本就由少数成员占优势。

**可以删掉离群点让图更整齐吗？** 先核对实验记录、污染和质量。排除须有独立理由并保留记录，不能仅因改变显著性而删样。

**为什么换分类器后菌名变了？** 参考库、分类体系、训练区域和版本会改变标签；可用同一代表序列追踪，但不能把不同名称体系直接混合。

**需要重新安装所有环境吗？** 先运行环境检查；仅补缺失依赖。绘图 R 与 QIIME 隔离，避免为修图破坏可用的 QIIME 环境。

排错时先找到最早失败的具体命令和错误，保留日志、当前版本与任务目录，再处理相应步骤。不要删除原始数据、关闭 TLS 校验或伪造成功标记来绕过问题。

## 18. 常用术语速查

| 术语 | 一句话解释 |
|---|---|
| ASV / OTU | 推断的精确扩增子变体 / 按规则聚类的序列单元 |
| Read / read pair | 单端读取序列 / 同一片段两端的一对读取 |
| Demultiplex | 用索引信息把混合文库拆分到样本 |
| Manifest / metadata | 输入文件映射 / 样本的分组和其他属性 |
| Denoise / chimera | 依据错误模型降噪 / 由多个模板形成的嵌合序列 |
| Taxonomy / phylogeny | 分类标签体系 / 序列推断的进化关系 |
| Richness / evenness | 检出成员有多少 / 各成员丰度是否均匀 |
| Prevalence | 在指定样本集合中满足检出条件的样本比例 |
| Rarefaction | 在指定计数深度进行无放回随机子抽样 |
| PCoA / PCA | 对距离矩阵 / 对数值矩阵进行低维排序 |
| Effect size / SE | 差异或关联幅度 / 估计值的标准误 |
| P / q / FDR | 原始检验信息 / 校正结果 / 错误发现率控制目标 |
| Structural zero / sampling zero | 模型判定的结构性缺失 / 有限抽样未检出 |
| CLR / Hellinger | 相对几何均值的对数比 / 相对丰度平方根变换 |
| NSTI / KO | 参考基因组的系统发育距离指标 / 功能同源组编号 |
| Provenance | 数据由哪些输入、工具、参数产生的来源记录 |
