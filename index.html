1 · 数据与分组

未拼接 clean R1/R2 仍选择双端。已拼接文件可检查与查看质量；当前 DADA2 流程需要未拼接 R1/R2 或真正单端。

未知状态不会自动视为 clean；检测证据不足时须补充真实引物或确认数据来源。

推荐四列 SampleID,Group,forward,reverse；后两列填写所选原始目录中的文件名。样本 ID 按 CSV 读取，保留前导零。

可新建在原始目录下，如 原始目录/results；每次创建独立 run 子目录，保留原始文件。

四列 CSV 明确指定样本、分组和每端文件，工作站自动读取，无需从文件名推断样本 ID。只处理 CSV 中列出的文件；原始目录中的其他 FASTQ 不纳入本次分析。双端需填写 forward 和 reverse，单端只填 forward、reverse 留空。

也兼容旧版两列 SampleID,Group，按 raw.A1.1/2.fq.gz、CAP1.raw_1/2.fastq、001_R1/R2.fastq.gz 等命名自动匹配；遇到歧义会提示。

分组顺序与统一配色

读取分组后，点击颜色自定义配色，用 ↑ / ↓ 调整各组在图中及图例中的顺序。保存后自动用于后续绘图；已有图片可使用重绘按钮更新。

统一设置用于工作站生成的 PNG / SVG / PDF。分类堆积图中菌种颜色表示分类单元，组别通过下方色带显示；QIIME 2 原生 QZV 的交互配色由其查看器控制。显示顺序不会改变差异检验的参考组。

可选：初次出图默认样式

可以直接按默认样式运行分析。出图后，在每张图片旁调整参数并预览；这里的设置只用于首次出图或整批重绘。

通用参数用于已有 R 图及 LEfSe 图，各图另有专用设置。数字留空沿用原版；尺寸单位为英寸（1英寸=2.54厘米）。配色与分组顺序仍使用上方统一设置；差异热图/气泡图的渐变色仍在差异分析区选择。

标题可用 {metric}、{rank}、{comparison}、{threshold} 等适用于该图的占位符。参数随任务保存；调整后点击各流程的“仅重绘”按钮即可，保持原始指标、坐标和 P/q 值。差异热图/气泡图仍为全部分组共同展示。

LEfSe 标志微生物

首次使用或缺少官方命令时，在 Ubuntu 的工作站源码目录执行 bash install_lefse.sh，安装到 lefse 环境并检查四个命令及 R 统计依赖。其他环境名可用 WORKSTATION_LEFSE_ENV=环境名 bash install_lefse.sh。

按每样本 ASV 总数转换为 CPM 一次，再构建分类谱系。模糊注释在对应层级不作为标志菌检验；完整谱系避免不同父分类的同名菌混合。分支图依据分类谱系绘制。

出图后到“图片与样式预览”调整 LDA 柱图及分类分支图。
