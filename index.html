1 · 数据与分组

支持 Phred33；已拼接的 clean 数据需确认处理方法。

推荐四列 SampleID,Group,forward,reverse；后两列填写所选原始目录中的文件名。样本 ID 按 CSV 读取，保留前导零。

可新建在原始目录下，如 原始目录/results；每次创建独立 run 子目录，保留原始文件。

四列 CSV 明确指定样本、分组和每端文件，工作站自动读取，无需从文件名推断样本 ID。只处理 CSV 中列出的文件；原始目录中的其他 FASTQ 不纳入本次分析。双端需填写 forward 和 reverse，单端只填 forward、reverse 留空。
查看 CSV 格式与文件填写说明
SampleID,Group,forward,reverse
A1,CON,raw.A1.1.fq.gz,raw.A1.2.fq.gz
CAP1,LDC,CAP1.raw_1.fastq,CAP1.raw_2.fastq
001,HDC,subfolder/001_R1.fastq.gz,subfolder/001_R2.fastq.gz

forward 是 R1，reverse 是 R2；可填文件名、相对于原始目录的子目录路径，或该目录内的绝对路径。检查时报告不存在、重复使用或目录外的文件。Excel 编辑后请另存为 CSV UTF-8，并把 SampleID 列设为文本，避免 Excel 去掉前导零。

也兼容旧版两列 SampleID,Group，按 raw.A1.1/2.fq.gz、CAP1.raw_1/2.fastq、001_R1/R2.fastq.gz 等命名自动匹配；遇到歧义会提示。

2 · 软件与分析参数

先检查你已安装的环境，再启动分析；不自动安装或升级现有 QIIME 2。

运行安装依赖.sh创建；与QIIME环境分开，避免旧系统R包冲突。

目录需包含 qiime2_io.R、plot_alpha_original_style.R、plot_beta_original_style.R。

必须匹配引物区域、QIIME 2 / scikit-learn 版本。

字体缺失会报错；DejaVu Serif 保留颜色、布局与统计方法。

先选择引物处理，再生成质量图。根据 trimmed.qzv / demux.qzv 填截断参数；预处理复用导入结果。

自动推荐根据抽样长度覆盖和质量变化选择截断；修改下面参数会切换手动模式。

质量检查完成后显示推荐及依据；旧版本质量结果也可使用此按钮，无需重新导入 FASTQ。

可选：有可靠长度时检查重叠≥12bp；不知道时留空，DADA2 仍按实际序列检查拼接。质量图不能推断这个长度。

检测前1000条的开头。未检出不证明已去除；正式分析前须确认引物处理和截断参数。

3 · 抽平深度与结果

预处理完成后自动推荐本次深度，并显示曲线依据和各组保留数量；可以手动修改。
当前流程输出：过滤后的 ASV 表、分类表、代表序列、系统发育树、分类堆积图、抽平曲线；抽平后 observed features / Shannon / evenness / Faith PD、四种 β 距离与 PCoA、α KW + 两两 KW/BH、β PERMANOVA/PERMDISP、额外 Chao1 / Simpson / Good’s coverage 指标、SVG 图和统计表。每次抽平独立保存，绘图复用本次指标和 P/q。常量数据等无法检验时会记录原因。

4 · 丰度、差异菌与功能预测

使用上方“已完成预处理的 run 目录”。这些分析读取过滤后未抽平表，不需重跑 FASTQ。旧版结果可单独补齐丰度表。

门到属差异菌分析

首次使用 ANCOM-BC2 时，在 Ubuntu 的工作站源码目录执行 bash install_differential.sh，创建专用环境。QIIME 2 ANCOM 使用已有 QIIME 环境；上面的 alpha/出现比例设置仅用于 ANCOM-BC2。

两者与原始 ANCOM-II 不同；按实际方法命名结果。

LEfSe 标志微生物

首次使用或缺少官方命令时，在 Ubuntu 的工作站源码目录执行 bash install_lefse.sh，安装到 lefse 环境并检查四个命令及 R 统计依赖。其他环境名可用 WORKSTATION_LEFSE_ENV=环境名 bash install_lefse.sh。

按每样本 ASV 总数转换为 CPM 一次，再构建分类谱系。模糊注释在对应层级不作为标志菌检验；完整谱系避免不同父分类的同名菌混合。分支图依据分类谱系绘制。

PICRUSt2 功能预测

KO 映射文件用于结果注释和 L1/L2/L3 汇总，参考数据库用于预测，两者分别选择。输出 KO、EC、MetaCyc、KEGG 层级及相对丰度；保存 NSTI 与可核实的排除情况。16S 功能预测属于推断。
